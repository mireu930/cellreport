### 주요 디렉토리 설명:
- clients: 외부 서비스와의 통신을 담당하는 클라이언트 모듈
- models: 앱에서 사용하는 데이터 구조 정의
- screens: 앱의 각 화면을 구성하는 위젯
- services: 비즈니스 로직을 처리하는 계층
- states: 앱의 상태 관리 로직
- theme: 앱의 디자인 시스템 정의
- utils: 유틸리티 함수 모음
- widgets: 여러 화면에서 재사용되는 공통 위젯
